=== More Ores（铅与铀） 安装说明 ===

适用版本：Minecraft 26.3（Java 25）+ Fabric Loader + Fabric API

1. 前置
   - 安装 Fabric Loader（对应 MC 26.3）。
   - 把 Fabric API 的 jar 放进 .minecraft/mods（本模组依赖它）。

2. 安装本模组
   - 把 moreores-1.0.0.jar 复制到：
       .minecraft/versions/<你的 Fabric 实例>/mods/
     或直接放进：
       .minecraft/mods/
   - 启动游戏，在「模组」列表里能看到 More Ores (lead & uranium)。

3. 新增内容速览
   - 矿石：铅、铀、钛（三种金属都有矿、粗矿、锭、粒、块、工具、护甲）。
   - 辐射系统：铀系物品 / 矿石会累积辐射剂量，铅甲按部位屏蔽，盖革计数器测剂量，
     牛奶瓶 / 牛奶解辐射。
   - 高能熔炉：只能烧本模组的「高能冶炼」配方（普通熔炉烧不了）。
   - 生物催化器：把树苗 / 种子催化成木头 / 作物。
   - 自然护符、核子电池、石英 / 各类种子等。

4. 配方自动解锁（本模组特性）
   - 所有本模组的新增合成表都会「自动解锁」：只要背包里出现配方里的
     任意一样东西（产物或原料），对应配方就在合成书里亮起，
     不必先亲手合成过。无需任何额外操作。

5. 备注
   - 这是开发版（版本号 1.0.0），建议在测试存档里先试一轮。
   - 卸载：直接从 mods 里删掉 jar 即可。
